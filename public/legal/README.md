# public/legal/ — 法務ドキュメントの置き場

利用規約とプライバシーポリシーの**本文だけ**をここに置く。
アプリ側（`public/js/views/legal.js`）が起動時に fetch して描画するため、
**この .md を書き換えて再デプロイすれば、それだけで反映される**（コードの変更は不要）。

## ファイル

| ファイル | 画面での呼び名 | URL |
|---|---|---|
| `terms-of-service.md` | 利用規約 | `/legal/terms-of-service.md` |
| `privacy-policy.md`   | プライバシーポリシー | `/legal/privacy-policy.md` |

## 改訂の手順

1. 該当の .md を書き換える
2. 冒頭の `版数：vX.Y` を更新する
3. コミットしてデプロイする

**★同意バージョンについて**：アカウント作成の STEP 0 で同意を取った時点の版数を
`users.consentVersion` に記録している。**規約を実質的に改訂したときは
`public/js/constants.js` の `CONSENT_VERSION` も併せて更新すること**
（更新しないと「どの版に同意したユーザーか」が追えなくなる）。
誤字修正など内容に影響しない変更では上げなくてよい。

## 対応している Markdown 記法

`legal.js` の `mdToHtml()` は下記のみを解釈する（外部ライブラリは使わない）。
これ以外の記法（画像・引用・コードブロック等）は素通しになるので使わないこと。

- 見出し `#` `##` `###`
- 段落（空行区切り）
- 箇条書き `- `
- 番号付きリスト `1. `
- 表 `| a | b |` ＋ 区切り行 `|---|---|`
- 強調 `**太字**`
- リンク `[表示文字](URL)`
- 水平線 `---`
